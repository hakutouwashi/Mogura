# もぐらたたき — 復元した開発用フォルダー

2026年11月25日に、ゴミ箱内の「もぐらたたき 16.55.52.app」からゲーム本体のソースを取り出し、Macの保存領域に残っていた謎画像12枚と設定を加えて復元しました。元の開発用フォルダーそのものの完全なコピーではありません。配布用の設定と起動コマンドは再作成しています。

## 起動

1. このフォルダーで `npm ci` を実行します。
2. `npm start` で全画面のゲームを起動します。編集しながら確認する場合は `npm run preview` を使います。

ゲーム設定は `settings.json` にあります。謎画像は `riddles/mole`、`riddles/fish`、`riddles/fruit`、`riddles/other` に入れます。画像は PNG、JPEG、WebP を読み込みます。選んだ「叩くもの」のフォルダーにある画像だけが正解で、残りの3フォルダーの画像は不正解です。さかな・くだものの画像はまだ入っていないため、追加するまでそれぞれのモードは開始できません。

タイトル画面の9マスはゲーム中と同じ配置の操作盤です。左の列を押すと前の「たたくもの」、右の列を押すと次の「たたくもの」に切り替わり、中央の列を押すとゲームを始めます。左右の方向キーでも切り替えられ、Enter・Spaceでも開始できます。数字キーは上段とテンキーの両方に対応します。

## 配布用ビルド

Mac版は `npm run build:mac`、Windows版は `npm run build:win` で作成します。出力先は `release` です。Mac版は署名と公証を行わない設定です。

## ブラウザ版

`npm run build:web` で、GitHub Pages に公開するファイルを `docs/` に生成します。ブラウザ版の設定は、そのブラウザのローカルストレージに保存されます。`renderer/` や `riddles/` を編集したら、公開前にこのコマンドを再実行してください。

## 復元元と限界

- `main/` と `renderer/`: 2026年11月19日の完成アプリに入っていたコード
- `riddles/` と `settings.json`: Macの `Library/Application Support/もぐらたたき` に残っていたデータ
- `build/icon.icns`: 同じ完成アプリ内のアイコン。`icon.png` はそこから変換
- `package.json`: アプリに入っていた基本情報をもとに、起動とビルドの設定を再作成

11月19日以降に元の開発フォルダーへ加えた変更や、テスト・開発用ツール・Gitの履歴は、この復元元には含まれていません。11月25日に別途作成されたブラウザ版は、このフォルダーとは別の成果物です。
